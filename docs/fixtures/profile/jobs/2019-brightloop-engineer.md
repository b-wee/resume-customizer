# Raw description

Startup, ~25 people, B2B analytics dashboards for e-commerce brands. I was one of
4 engineers, did everything.

Built the ingestion pipeline that pulled order data from Shopify/Amazon APIs into
Postgres — eventually handling ~2M orders/day across ~180 customer accounts. First
version was cron + Python scripts, I rebuilt it on Kafka when we started dropping data.

Owned the customer-facing dashboard (React + Django REST). Shipped the cohort
analysis feature that sales said closed our two biggest deals that year.

Set up all the infra basically from scratch: Terraform, CI on GitHub Actions,
moved us from Heroku to AWS ECS which cut hosting costs ~45%.

Onboarded 2 junior hires. Company was acquired in 2021.
